> **Orbita** is an all-in-one personal productivity & financial intelligence workspace. It seamlessly unifies daily task management, event scheduling, multi-wallet cash flow tracking, and a context-aware AI assistant inside a modern, responsive, anti-slop interface.

---

## 📌 Overview

Orbita is engineered around quiet luxury design principles — prioritizing visual ergonomics, clear information hierarchy, and sub-second responsiveness across desktop and mobile devices.

| Core Module | Description |
| :--- | :--- |
| 📋 **Task Management** | Complete daily to-do workflows featuring quick status toggles, paginated history, and date range filtering. |
| 🗓️ **Agenda & Reminders** | Interactive event planner with monthly calendar grid, upcoming & past tabs, date range filters, and Web Push notifications. |
| 💳 **Finance & Wallets** | Multi-wallet cash flow ledger (income & expenses), 7-day trend charts, custom categories, and paginated transaction history. |
| 🤖 **AI Assistant (Orbita Bot)** | Smart assistant powered by Google Gemini 2.5 Flash that inspects account context in real-time, provides insights, and generates draft actions with fast typewriter animation. |

## ⚡ Tech Stack

### 🚀 Core & Framework
```
 ⚛️ React 19.1.0        · Full App Router Architecture
 📐 TypeScript 5.7      · Strict Type-Safety & Server Actions
 ⚡ Next.js 16.3.1       · Server-Side Rendering & Edge-Ready APIs
```

### 🗄️ Backend & Database
```
 🐘 Neon Postgres       · Serverless PostgreSQL Architecture
 🔐 Neon Auth           · JWT-authenticated session & RLS scoping
 🛡️ Neon Data API       · Row Level Security (RLS) via auth.user_id()
 🤖 Gemini 2.5 Flash    · Streaming SSE via Generative Language API
```

### 🎨 Design System & UI
```
 🎨 Vanilla CSS3        · Quiet luxury design tokens, Dark/Light Mode, CSS variables
 🎬 Framer Motion       · Micro-animations & fluid layout transitions
 🧩 Lucide Icons        · Clean, lightweight vector iconography
 🔔 Web Push API        · Service worker background push notifications
```
