# Orbita UI decisions

Design read: personal daily command center for individual users, using a calm, dark-first analytical language. Dials: ENERGY 1, RHYTHM 2, MOTION 2.

- Color: indigo is reserved for the current location and primary action so focus is visible without coloring every surface.
- Layout: a persistent desktop rail becomes a bottom navigation on mobile because primary destinations must remain reachable by thumb.
- Typography: Inter and system fallbacks keep dense task metadata readable; tabular numerals remain available for the finance module.
- Spacing: broad desktop margins create a calm work surface, while the mobile scale is tighter to preserve usable vertical space.
- Cards: one main task surface establishes a clear focal point; nested card grids are avoided because the task list is the actual content.
- Motif: a thin tilted orbital ring repeats in the wordmark and empty state to give Orbita a recognizable visual gesture without assuming a final logo.
- Motion: short enter, exit, and undo transitions explain state changes; reduced-motion preferences disable nonessential movement.
- Theme: dark follows the supplied design direction, while a working light theme gives users control in brighter environments.
